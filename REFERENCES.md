## How to add an entry

Before adding a file, a library, an image, a font, or text from outside:

1. Find its license. If there is none, or it is unclear, do not use it.
2. Check that the license allows the use (bundling, modifying).
3. Add a row to the right table above, with the source and version.
4. If the file is copied into the repository, copy its license file next to it.
