# Desktop clients

Two separate Flutter desktop apps, written in Dart.

| Folder | For | Does |
|---|---|---|
| [`customer-app/`](customer-app/README.md) | Customers | Log in, register, search books, select and order them, see the bill. **Built** |
| [`management-app/`](management-app/README.md) | Managers | View orders and their bills, update payment status, add and update books. **Built** |
| [`bookstore-ui/`](bookstore-ui/README.md) | Both apps | The shared look (colors, typefaces, spacing, motion, common widgets) and the shared service clients, session, and data |

Both apps are built and work against the real services.

**If `flutter run` fails with hundreds of "Type not found" errors** from the Terminal panel of the Claude app: that panel could not read the package folder (`%LOCALAPPDATA%\Pub\Cache`). Run it from a normal PowerShell window or VS Code instead (problem log, P-013).

The `windows/` folder of each app was generated by `flutter create`: it is the small C++ and CMake program that opens the window and starts Flutter. Nothing in it was written for this project; `.gitattributes` keeps it out of GitHub's language statistics.

Design: [UI](../docs/02-design/ui-design.md), [class diagrams](../docs/02-design/class-diagrams.md).

## Running an app

**In VS Code:** open the Run and Debug panel (Ctrl+Shift+D), pick "Customer app" or "Management app", and press F5. Saving a file while it runs updates the window immediately (hot reload).

**From a terminal:**

```bash
cd clients/customer-app
```

```bash
flutter run -d windows
```

## One-time setup on a new machine

1. Install the [Flutter SDK](https://docs.flutter.dev/get-started/install/windows/desktop) and add its `bin` folder to PATH.
2. Install Visual Studio 2022 Build Tools with the "Desktop development with C++" workload (Flutter needs it to compile Windows apps).
3. In VS Code, install the "Flutter" extension (it brings the Dart extension with it).
4. Run `flutter doctor` and fix anything it marks with a cross for Windows.
