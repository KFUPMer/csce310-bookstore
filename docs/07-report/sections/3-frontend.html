3. Frontend design

Two Windows desktop apps built with Flutter: Mooney's for customers and Mooney's Manager for managers. Both share one look (clients/bookstore-ui), light and dark. Every call to a service is asynchronous, so the window never freezes (N2). The screenshots are the real app screens, drawn by the apps' tests. The wireframes made before building are in docs/02-design/diagrams.
